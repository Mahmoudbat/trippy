# Photography credits

Photographs are local Wikimedia Commons assets. Each is resized and converted to WebP, with no change to the depicted content. Retain the author, source, license and modification notice when redistributing. Follow each license link for its terms. Original SVG placeholder artwork is labeled as an illustration.

The Jordan boundary and Dead Sea shapes in `assets/jordan-map.svg` are adapted from [Natural Earth](https://www.naturalearthdata.com/), 1:50m Admin 0 Countries and Lakes datasets, which are public domain. Styling, labels and the interactive destination overlay are original to this project.
